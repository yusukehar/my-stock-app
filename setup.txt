Python 3.9.6 が入っていることが確認できて良かったです！MacBook Air（デフォルトの状態）であれば標準的なバージョンです。

では、VS Codeのターミナル（`my-stock-app` フォルダ）で、以下の手順を**一気に**進めてアプリを起動させましょう。

### 1. 仮想環境の作成と有効化

まずは、このプロジェクト専用の「道具箱（仮想環境）」を作ります。

```bash
# 仮想環境を作る
python3 -m venv venv

# 仮想環境を起動する
source venv/bin/activate

```

※ 成功すると、行の先頭に `(venv)` と表示されます。

### 2. 必要なライブラリのインストール

次に、アプリを動かすための部品を入れます。

```bash
pip install streamlit yahooquery plotly pandas

```

### 3. app.py の作成と保存

VS Codeの左側のファイル一覧（エクスプローラー）で `my-stock-app` フォルダ内に新しいファイルを作り、名前を **`app.py`** にします。

そこに、先ほどお渡ししたコード（`st.title` などが入ったもの）を貼り付けて保存（Cmd + S）してください。

### 4. アプリの起動

いよいよ起動です！

```bash
streamlit run app.py

```

---

### よくあるトラブルと対処法

もし `streamlit run app.py` を打った後にエラーが出たら、以下を確認してください。

* **「zsh: command not found: streamlit」と出る場合**
→ 手順2の `pip install` が終わっていないか、手順1の `source venv/bin/activate` を忘れている可能性があります。もう一度実行してみてください。
* **「ModuleNotFoundError: No module named 'yahooquery'」と出る場合**
→ 仮想環境の中で正しくインストールできていません。もう一度 `pip install yahooquery` を実行してください。

### 起動に成功すると...

ターミナルに以下のようなメッセージが表示され、自動的にブラウザが開きます。

> **Local URL:** http://localhost:8501
> **Network URL:** [http://192.168.](https://www.google.com/search?q=http://192.168.)x.x:8501

ブラウザに **「📈 株価分析プロトタイプ」** というタイトルが表示されたら、ローカル開発環境の構築は**完全成功**です！
